# brief/ — Stage 1

One brief per piece of work: problem, what done looks like, approach, and
what's out of scope. Named `<slug>.md`, where the slug is also the branch
name and starts with a sequence number (`007-csv-export`) — the sdlc skill
says how to pick it. Copy `TEMPLATE.md` to start, or let Claude write it.

Briefs can wait here: write several on a `backlog-*` branch and merge them,
and `/sdlc` offers them as not started until one gets a branch. Whether a
brief is done, in progress or not started is read off git — there's no
status field to keep up to date. To drop one, delete it in a PR.
`.claude/skills/sdlc/SKILL.md` "Which streams exist" has the rules.

How to write one: `.claude/skills/sdlc/stages/1-brief.md`.
